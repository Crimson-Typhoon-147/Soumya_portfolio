Entropylane

EntropyLane is a secure messaging project that generates cryptographic randomness from real-world traffic video patterns to create encryption keys. It combines an AES-256-GCM FastAPI backend with a React chat interface to demonstrate session-based encrypted communication with real-time security status.

ProofVault

ProofVault is a blockchain-based digital evidence verification system designed to ensure authenticity and tamper-proof integrity of critical records. It provides secure timestamping, traceable ownership, and trustworthy proof storage for use cases like law enforcement, legal documentation, and land record validation.
